# 📝 1장 파이썬 소개 요약

컴퓨터는 하드웨어와 소프트웨어로 구성되며 다양한 작업을 수행할 수 있는 유연한 기계이다. 컴퓨터가 일을 하려면 사람이 명령어를 작성해야 하며, 이러한 명령어들의 집합을 프로그램이라고 한다.
오늘날 프로그래밍은 인공지능, 자동 주식 매매, 로봇 프로세스 자동화(RPA) 등 다양한 분야에서 활용되고 있다. 컴퓨터는 반복적이고 지루한 작업을 빠르고 정확하게 처리하는 데 강점을 가진다.
컴퓨터는 사람의 언어를 이해하지 못하기 때문에 프로그래밍 언어가 필요하다. 사람이 작성한 프로그램은 컴파일러나 인터프리터를 통해 컴퓨터가 이해할 수 있는 기계어로 변환되어 실행된다.
파이썬은 문법이 간단하고 배우기 쉬운 인터프리터 언어이다. 실행 결과를 바로 확인할 수 있어 초보자에게 적합하며, 다양한 라이브러리를 지원하여 데이터 분석, 인공지능, 웹 개발 등 여러 분야에서 사용된다.
파이썬은 대화형 모드와 스크립트 모드를 지원한다. 또한 print() 함수를 사용하여 문자열이나 계산 결과를 출력할 수 있으며, 문자열은 큰따옴표 또는 작은따옴표 안에 작성해야 한다. 파이썬은 대소문자를 구분하며 소스 파일의 확장자는 .py이다.

## 1. 문자열

문자열은 큰따옴표(" ") 또는 작은따옴표(' ')로 감싸야 한다.

```python
print("Hello")
```

## 2. print() 함수

화면에 문자열이나 계산 결과를 출력한다.

```python
print("파이썬에 오신 것을 환영합니다.")
print("2+3=", 2+3)
```
