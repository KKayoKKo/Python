# 1장 파이썬 소개 요약

## 컴퓨터와 프로그램

컴퓨터는 하드웨어와 소프트웨어로 구성된다. 컴퓨터에게 일을 시키기 위해 작성하는 명령어들의 집합을 프로그램이라고 한다. 컴퓨터는 반복적인 작업을 빠르고 정확하게 수행한다.

## 프로그래밍 언어

컴퓨터는 사람의 언어를 이해하지 못하므로 프로그래밍 언어가 필요하다. 사람이 작성한 코드는 컴파일러나 인터프리터를 통해 기계어로 변환된다.

## 파이썬

파이썬은 배우기 쉽고 문법이 간결한 프로그래밍 언어이다.

### 특징

* 배우기 쉽다.
* 결과를 바로 확인할 수 있다.
* 라이브러리가 풍부하다.
* 인공지능, 데이터 분석, 웹 개발 등에 사용된다.

## 개발 환경

* Anaconda : 파이썬 배포판
* Spyder : 파이썬 개발 도구
* Jupyter Notebook : 코드와 설명을 함께 작성 가능
* Google Colab : 웹에서 파이썬 실행 가능

## 문자열

문자열은 큰따옴표(" ") 또는 작은따옴표(' ')로 감싸야 한다.

```python
print("Hello")
```

## print() 함수

화면에 문자열이나 계산 결과를 출력한다.

```python
print("파이썬에 오신 것을 환영합니다.")
print("2+3=", 2+3)
```

## 실행 모드

* 대화형 모드 : 한 줄씩 실행
* 스크립트 모드 : 파일 전체 실행

## 주의사항

* 파이썬은 대소문자를 구분한다.
* 문자열에는 따옴표가 필요하다.
* 소스 파일 확장자는 `.py` 이다.

## 핵심 정리

* 프로그램은 명령어들의 집합이다.
* 파이썬은 쉽고 활용 범위가 넓다.
* `print()` 함수로 출력한다.
* 문자열은 따옴표로 묶는다.
* 파이썬 파일 확장자는 `.py`이다.
