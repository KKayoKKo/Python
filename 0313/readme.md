# 📝 Chapter 2. 변수와 수식

## 1. 변수 (Variable)

* **정의**: 데이터를 저장하는 메모리 공간의 이름.


* **원리**: 값이 변수 상자에 직접 담기는 것이 아니라, 데이터 **객체의 주소(참조값)를 가리키는 방식**.


* **명명 규칙**: 영문/숫자/밑줄(`_`) 사용 가능, 숫자로 시작 불가, 대소문자 구분, 공백 불가.


* **낙타체 (Camel Case)**: 단어 결합 시 첫 단어는 소문자, 뒤는 대문자로 표기 (예: `myNewCar`).



## 2. 자료형 (Data Type)

파이썬의 핵심 표준 자료형 종류는 다음과 같습니다. 

* **정수 (`int`)** / **실수 (`float`)** / **문자열 (`str`)** 


* **불변 객체**: 정수, 실수, 문자열, 튜플 (값 변경 시 새로운 메모리 주소 생성).


* **가변 객체**: 리스트, 딕셔너리, 세트 (기존 데이터 직접 수정 가능).


* `type()` 함수로 변수의 자료형을 확인할 수 있습니다.



## 3. 주석과 상수

* **주석 (`#`)**: 코드 실행을 건너뛰는 설명글 및 의석화 용도.


* **상수**: 프로그램 내에서 변하지 않는 값. 문법적 강제성은 없으나 관례상 **대문자**로 작성 (`PI = 3.14`).



## 4. 연산자 (Operators)

### ➖ 산술 연산자

* `//` : 나눗셈의 **몫** (정수) 


* `%` : 나눗셈의 **나머지** 


* `` : **지수** (거듭제곱) 



### 📝 다중 할당 및 복합 대입

* **다중 할당**: `x, y = 10, 20` (한 줄 초기화) 


* **값 교환**: `x, y = y, x` (임시 변수 없이 스왑) 


* **복합 대입**: `x += y` (즉, `x = x + y`) 



## 5. 문자열 (String) 기초

* **표현**: 큰/작은따옴표 모두 가능하며, 여러 줄은 세 따옴표(`"""` 또는 `'''`) 사용.


* **연산**: `+`는 결합, `*`는 반복 수행.


* **인덱싱**: `s[0]`은 첫 글자, `s[-1]`은 마지막 글자 반환.


* **변환**: `int("100")` ➡️ 정수 변환 / `str(100)` ➡️ 문자열 변환.



## 6. 입력과 출력 (I/O)

* **`input()`**: 사용자 입력을 받으며, 결과는 항상 문자열(`str`)로 반환. (숫자 계산 시 `int()[cite_start]`나 `float()` 변환 필수) 


* **f-string (형식화)**: 변수와 문자열을 간결하게 동시 출력.


```python
print(f"{x}와 {y}의 합 = {x + y}")

```
