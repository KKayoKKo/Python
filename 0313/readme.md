# 📝 2장 변수와 수식

변수는 데이터를 저장하기 위해 사용하는 이름이다. 파이썬에서 변수는 데이터 자체를 저장하는 것이 아니라 데이터 객체의 주소(참조값)를 가리킨다. 변수 이름은 영문, 숫자, 밑줄(_)을 사용할 수 있으며 숫자로 시작할 수 없다. 또한 대소문자를 구분하고 공백은 사용할 수 없다.

파이썬의 기본 자료형에는 정수(int), 실수(float), 문자열(str)이 있다. 정수, 실수, 문자열, 튜플은 값을 변경할 수 없는 불변 객체이며, 리스트와 딕셔너리, 세트는 값을 변경할 수 있는 가변 객체이다. 자료형은 `type()` 함수를 사용하여 확인할 수 있다.

주석은 `#` 기호를 사용하여 작성하며 코드에 대한 설명이나 메모를 남길 때 사용한다. 상수는 프로그램 실행 중 값이 변하지 않는 데이터로, 관례상 대문자로 작성한다.

파이썬은 다양한 연산자를 제공한다. `//`는 나눗셈의 몫을 구하고, `%`는 나머지를 구하며, `**`는 거듭제곱을 계산한다. 또한 다중 할당을 사용하여 여러 변수에 값을 한 번에 저장할 수 있고, `x, y = y, x` 형태로 임시 변수 없이 값을 교환할 수 있다.

문자열은 큰따옴표 또는 작은따옴표 안에 작성하며, `+` 연산자로 문자열을 연결하고 `*` 연산자로 반복할 수 있다. 또한 인덱싱을 통해 원하는 위치의 문자를 가져올 수 있으며, `int()`, `float()`, `str()` 함수를 사용하여 자료형을 변환할 수 있다.

입력은 `input()` 함수를 사용하며 입력받은 값은 항상 문자열로 저장된다. 따라서 숫자 계산을 위해서는 `int()` 또는 `float()` 함수를 사용하여 자료형을 변환해야 한다. 출력은 `print()` 함수를 사용하며, f-string을 이용하면 변수와 문자열을 쉽게 함께 출력할 수 있다.

## 1. 입력과 출력

* **`input()`**: 사용자 입력을 받으며, 결과는 항상 문자열(`str`)로 반환. (숫자 계산 시 `int()[cite_start]`나 `float()` 변환 필수) 

* **f-string (형식화)**: 변수와 문자열을 간결하게 동시 출력.


```python
x = int(input("첫 번째 수 입력: "))
y = int(input("두 번째 수 입력: "))

print(f"{x}와 {y}의 합 = {x+y}")

```
