#  📝 3장 조건문

조건문은 프로그램의 실행 순서를 변경하는 제어문 중 하나이다. 프로그램의 기본 구조는 순차구조, 선택구조, 반복구조로 나뉘며, 조건문은 선택구조를 구현하는 데 사용된다. 조건문이 없으면 프로그램은 항상 같은 동작만 반복하므로 입력값이나 상황에 따라 다른 결과를 처리하기 위해 필요하다.
파이썬에서는 `if`와 `else`를 사용하여 조건에 따라 다른 문장을 실행할 수 있다. 조건식이 참(True)이면 `if` 블록이 실행되고, 거짓(False)이면 `else` 블록이 실행된다. 여러 문장을 실행할 경우 들여쓰기를 사용하여 블록을 구성해야 하며, `if`와 `else` 뒤에는 반드시 콜론(`:`)을 작성해야 한다.
조건식에는 관계 연산자를 사용한다. `==`, `!=`, `<`, `>`, `<=`, `>=` 등을 이용하여 값의 크기나 같은지 여부를 비교할 수 있다. 또한 부울(Boolean) 자료형은 `True`와 `False` 두 가지 값만 가지며 조건문의 결과를 저장하는 데 사용된다.
여러 조건을 함께 검사할 때는 논리 연산자를 사용한다. `and`는 모든 조건이 참일 때 참이 되고, `or`는 하나라도 참이면 참이 된다. `not`은 참과 거짓을 반대로 바꾼다. 또한 조건 연산자를 사용하면 간단한 `if-else` 문을 한 줄로 작성할 수 있다.
여러 개의 조건을 처리할 때는 `elif`를 사용한다. 프로그램은 위에서부터 차례대로 조건을 검사하며, 참이 되는 조건의 블록 하나만 실행한다. 또한 `if` 문 안에 또 다른 `if` 문을 사용하는 중첩 조건문도 사용할 수 있다.

## 1. `if-else` 문 기초

* **기본 형식**: 조건식이 참(`True`)이면 문장1을, 거짓(`False`)이면 문장2를 실행합니다.


```python
if 조건식:
    문장1  # 조건식이 참일 때 실행
else:
    문장2  # 조건식이 거짓일 때 실행

```

## 2. 다중 선택 구조 (`elif` 및 중첩 `if`)

* **중첩 `if` 문**: `if` 문 내부에 또 다른 `if` 문을 집어넣어 더 세부적인 조건을 검사합니다. (예: 배송지 국가를 먼저 확인한 뒤, 국가별 상품 가격 기준에 따라 배송비 책정) 
* **연속 `if` (또는 `elif`) 문**: 여러 개의 조건 중 하나를 선택하여 실행할 때 사용하며, 위에서부터 차례대로 조건을 검사하다가 참인 블록 하나만 실행합니다.


```python
if score >= 90:
    print("학점 A")
elif score >= 80:
    print("학점 B")
else:
    print("학점 F")

```
