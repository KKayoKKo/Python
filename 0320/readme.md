#  📝 3장 조건문

## 1. 제어구조와 조건문

* **제어문 종류**: 문장의 실행 순서를 바꾸는 제어문은 **조건문**과 **반복문**으로 나뉩니다.


* **3가지 기본 제어구조**: 프로그램은 **순차구조, 선택구조, 반복구조**로 흘러갑니다.


* **조건문의 중요성**: 조건문이 없다면 프로그램은 항상 동일한 동작만 되풀이하므로, 외부 상황이나 입력값에 대응하기 위해 반드시 필요합니다.



## 2. `if-else` 문 기초

* **기본 형식**: 조건식이 참(`True`)이면 문장1을, 거짓(`False`)이면 문장2를 실행합니다.


```python
if 조건식:
    문장1  # 조건식이 참일 때 실행
else:
    문장2  # 조건식이 거짓일 때 실행

```


* **블록(Block)과 들여쓰기**: 조건에 따라 실행할 문장이 여러 개일 경우 동일한 간격으로 들여쓰기를 해야 하며, 이를 복합문(블록)이라고 합니다.


* **주의사항**: `if`와 `else` 뒤에는 콜론(`:`)을 붙여야 하며, 두 키워드는 동일한 위치(들여쓰기 라인)에 있어야 합니다. `else` 절은 필요에 따라 생략 가능합니다.



## 3. 관계 연산자와 부울(Boolean)

* **관계 연산자**: 조건식에는 참/거짓을 판별하는 연산자(`==`, `!=`, `<`, `>`, `<=`, `>=`)를 사용합니다.


* **부울 변수 (`bool`)**: `True` 또는 `False` 값만 가지는 변수입니다. 관계 수식의 결과를 변수에 직접 저장하여 사용할 수 있습니다.


* **비교 특징**:
* 문자열도 사전 순서를 기준으로 크기 비교(`s1 < s2`)가 가능합니다.


* 실수를 비교할 때는 정밀도 문제 때문에 `==` 대신 오차 범위값(`abs(a - b) < 0.00001`)을 비교하는 것이 안전합니다.





## 4. 논리 연산자와 조건 연산자

* **논리 연산자**: 여러 조건을 조합할 때 사용합니다.
* `and`: 두 조건이 모두 참일 때 참 


* `or`: 두 조건 중 하나라도 참이면 참 


* `not`: 참을 거짓으로, 거짓을 참으로 반전 




* **드모르간의 법칙**: `not` 연산자가 포함된 복잡한 논리식을 직관적이고 단순하게 변환할 때 유용합니다.


* **조건 연산자 (삼항 연산자)**: `if-else` 문을 한 줄로 간결하게 줄여 변수에 대입하는 방식입니다.


```python
#형식: (참일 때 값 if 조건식 else 거짓일 때 값)
absolute_value = (x if x > 0 else -x)

```



## 5. 다중 선택 구조 (`elif` 및 중첩 `if`)

* **중첩 `if` 문**: `if` 문 내부에 또 다른 `if` 문을 집어넣어 더 세부적인 조건을 검사합니다. (예: 배송지 국가를 먼저 확인한 뒤, 국가별 상품 가격 기준에 따라 배송비 책정) 


* **연속 `if` (또는 `elif`) 문**: 여러 개의 조건 중 하나를 선택하여 실행할 때 사용하며, 위에서부터 차례대로 조건을 검사하다가 참인 블록 하나만 실행합니다.


```python
if score >= 90:
    print("학점 A")
elif score >= 80:
    print("학점 B")
else:
    print("학점 F")

```

## 📌 핵심 요약

1. 프로그램의 실행 흐름을 바꾸는 구조에는 **조건문**과 **반복문**이 있다.


2. 조건에 따라 실행되는 문장들은 반드시 동일한 너비로 들여쓰기(블록)를 해야 한다.


3. `input()` 등으로 받은 값의 범위를 검사하여 **사용자 입력 값의 유효성을 검증**할 수 있다.


4. 세 가지 이상의 다중 조건을 처리할 때는 **`elif`** 구문을 활용한다.


5. 간결한 코드 작성을 위해 한 줄짜리 **조건 연산자**를 지원한다.
