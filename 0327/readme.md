# 📝 제4장 반복문

## 1. 반복문(Loop)의 필요성

* **정의**: 동일하거나 유사한 일련의 명령어들을 여러 번 실행하도록 제어하는 구조입니다.
* **중요성**: 반복적이고 단순한 작업을 자동화하여 코드의 중복을 줄이고 프로그래밍의 효율성을 극대화합니다.
* **종류**: 파이썬은 횟수가 정해진 반복을 위한 **`for` 문**과 조건에 따라 반복하는 **`while` 문**을 제공합니다.

## 2. `for` 문과 `range()` 함수

정해진 횟수만큼 순회하거나 시퀀스(리스트, 문자열 등)의 요소를 차례대로 처리할 때 사용합니다.

### 🔄 `range()` 함수 활용법

* `range(종료값)`: 0부터 (종료값 - 1)까지 1씩 증가 (예: `range(5)` ➡️ 0, 1, 2, 3, 4)
* `range(시작값, 종료값)`: 시작값부터 (종료값 - 1)까지 1씩 증가 (예: `range(1, 6)` ➡️ 1, 2, 3, 4, 5)
* `range(시작값, 종료값, 증감값)`: 지정한 증감값 크기만큼 건너뛰며 생성 (예: `range(1, 10, 2)` ➡️ 1, 3, 5, 7, 9)

```python
# 5번 반복하며 0부터 4까지 출력
for i in range(5):
    print(i)

```

## 3. `while` 문

조건식이 **참(`True`)인 동안** 문장을 계속해서 반복 실행합니다. 조건이 거짓(`False`)이 되면 루프를 빠져나옵니다.

* **기본 형식**:
```python
while 조건식:
    문장  # 조건식이 참일 때 반복 실행

```


* **사용 처**: 반복 횟수를 미리 알 수 없고, 특정 조건이 만족될 때까지 계속 실행해야 하는 경우에 적합합니다.

### ⚠️ 무한 루프 (Infinite Loop)

* 조건식이 항상 `True`여서 루프가 영원히 끝나지 않는 현상입니다.
* 프로그램이 멈추지 않으므로 주의해야 하지만, 대화형 프로그램이나 게임 루프 등 **특정 이벤트를 기다리는 환경**에서는 의도적으로 사용되기도 합니다.

## 4. 중첩 반복문 (Nested Loop)

반복문 내부에 또 다른 반복문을 포함하는 구조입니다.

* 외부 루프가 한 번 실행될 때마다 내부 루프는 지정된 횟수만큼 처음부터 끝까지 전체 순회합니다.
* 대표적인 활용 예시: **구구단 출력**, 2차원 평면 좌표 처리 등.

```python
# 구구단 2단~9단 출력 예시
for i in range(2, 10):
    for j in range(1, 10):
        print(f"{i} * {j} = {i*j}")

```

## 5. 루프 제어: `break`와 `continue`

반복문의 흐름을 강제로 바꾸는 키워드입니다.

* **`break`**: 반복문 블록을 즉시 **탈출**하고 무조건 루프를 종료합니다. (보통 무한 루프 내에서 특정 탈출 조건을 만족했을 때 사용)
* **`continue`**: 루프 안의 나머지 문장들을 건너뛰고, 반복문의 **다음 차례(다음 반복)로 즉시 넘어갑니다**.
