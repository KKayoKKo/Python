# 📝 제4장 반복문

### 4장 반복문 요약

반복문은 동일하거나 비슷한 명령어를 여러 번 실행하기 위해 사용하는 제어문이다. 반복문을 사용하면 같은 코드를 여러 번 작성할 필요가 없어 프로그램을 더욱 효율적으로 만들 수 있다. 파이썬에서는 `for` 문과 `while` 문을 사용하여 반복 작업을 수행한다.
`for` 문은 반복 횟수가 정해져 있거나 리스트, 문자열과 같은 시퀀스의 요소를 순서대로 처리할 때 사용한다. 주로 `range()` 함수와 함께 사용하며, `range()` 함수는 일정한 규칙을 가진 숫자들의 범위를 생성한다.
`while` 문은 조건식이 참인 동안 계속 반복 실행된다. 반복 횟수를 미리 알 수 없거나 특정 조건이 만족될 때까지 작업을 수행해야 하는 경우에 사용한다. 조건이 항상 참이면 무한 루프가 발생할 수 있으므로 주의해야 한다.
반복문 안에 또 다른 반복문을 넣을 수 있는데 이를 중첩 반복문이라고 한다. 중첩 반복문은 구구단 출력이나 2차원 데이터 처리와 같은 작업에 자주 활용된다.
반복문의 실행 흐름을 제어하기 위해 `break`와 `continue`를 사용할 수 있다. `break`는 반복문을 즉시 종료하며, `continue`는 현재 반복의 나머지 코드를 건너뛰고 다음 반복으로 이동한다.

## 1. `for` 문과 `range()` 함수

* **기본 형식**: `range()` 함수로 생성한 숫자 범위를 차례대로 반복하며 실행한다.

```python
for i in range(5):
    print(i)
```

## 2. `while` 문

* **기본 형식**: 조건식이 참(`True`)인 동안 반복 실행한다.

```python
num = 1

while num <= 5:
    print(num)
    num += 1
```

## 3. `break`와 `continue`

* **`break`**: 반복문을 즉시 종료한다.
* **`continue`**: 현재 반복을 건너뛰고 다음 반복으로 이동한다.

```python
for i in range(1, 6):
    if i == 3:
        continue
    print(i)
```
