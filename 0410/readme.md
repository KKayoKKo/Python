# 📝 5장 함수

## 1. 코드를 묶는 방법과 함수의 필요성

* **코드 조직화**: 프로그램이 커지면 관련 있는 코드를 묶어 구조화해야 합니다. (함수, 객체, 모듈 활용)
* **함수(Function)란?**: 특정 작업을 수행하는 명령어들의 모음에 이름을 붙인 **프로그램의 빌딩 블록**입니다.
* **필요성**:
* 중복된 코드를 제거하여 소스 코드의 재사용성을 높입니다.
* 복잡한 프로그램을 여러 개의 작은 부분(모듈)으로 분할하여 개발 및 유지보수를 쉽게 만듭니다.



## 2. 함수의 구조 및 정의/호출

* **정의 (`def`)**: `def` 키워드를 사용하며, 함수 이름 뒤에 콜론(`:`)을 붙이고 실행할 문장들을 들여쓰기합니다.
* **호출**: 함수 이름을 쓰고 괄호 안에 인수를 넣어 실행합니다. (정의를 먼저 해야 호출할 수 있습니다.)

```python
# 함수 정의
def greet():
    print("안녕하세요!")

# 함수 호출
greet()

```

## 3. 매개변수(Parameter)와 인수(Argument)

* **매개변수**: 함수를 정의할 때 외부에서 값을 넘겨받기 위해 선언하는 변수입니다.
* **인수**: 함수를 호출할 때 실제로 매개변수에 전달하는 값입니다.

```python
def say_hello(name):  # name = 매개변수
    print(f"안녕, {name}!")

say_hello("태욱")      # "태욱" = 인수

```

## 4. 반환값 (`return`)

* 함수 내부에서 작업을 수행한 후, 그 결과를 호출한 곳으로 다시 돌려주는 기능입니다.
* 반환값이 없는 함수는 파이썬 내부적으로 `None`을 반환합니다.
* 하나의 함수에서 여러 개의 값을 쉼표(`,`)로 구분하여 동시에 반환할 수 있습니다. (이때 결과는 튜플 형태로 반환됨)

```python
def add(a, b):
    return a + b  # 결과값 반환

```

## 5. 변수의 범위: 지역 변수 vs 전역 변수

변수가 프로그램의 어느 부분에서 선언되었느냐에 따라 사용 가능한 범위가 달라집니다.

* **지역 변수 (Local Variable)**: 함수 내부에서 생성된 변수입니다. 해당 함수 안에서만 사용 가능하며, 함수가 종료되면 메모리에서 소멸합니다.
* **전역 변수 (Global Variable)**: 함수 외부(메인 프로그램)에서 생성된 변수입니다. 프로그램 전체에서 읽을 수 있습니다.
* **`global` 키워드**: 함수 내부에서 전역 변수의 값을 수정(변경)하고자 할 때 사용합니다.

```python
gx = 100  # 전역 변수

def my_func():
    global gx  # 전역 변수 gx를 사용하겠다고 선언
    gx = 200   # 전역 변수 값 변경

```

## 📌 핵심 요약 (Summary)

1. **함수**는 특정 작업을 수행하는 재사용 가능한 명령어들의 집합이다.
2. 함수는 **`def`** 키워드로 정의하고, 필요한 데이터를 **매개변수**로 받으며 `return`으로 결과를 반환한다.
3. 함수 내부에서 만들어진 **지역 변수**는 함수가 끝나면 사라지며, 외부의 **전역 변수**와는 독립적이다.
4. 함수 안에서 전역 변수의 값을 직접 수정하려면 **`global`** 키워드를 먼저 선언해야 한다.
5. 파이썬 함수는 한 번에 **여러 개의 값**을 동시에 반환할 수 있다.
