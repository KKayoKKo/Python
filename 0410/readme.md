# 📝 5장 함수

### 5장 함수 요약

함수는 특정 작업을 수행하는 명령어들의 집합으로, 프로그램을 구조적으로 작성하고 코드를 재사용하기 위해 사용한다. 함수를 사용하면 중복된 코드를 줄일 수 있으며, 프로그램을 여러 개의 작은 기능으로 나누어 개발과 유지보수를 쉽게 할 수 있다.
파이썬에서는 `def` 키워드를 사용하여 함수를 정의한다. 함수는 정의한 후 함수 이름과 괄호를 사용하여 호출할 수 있으며, 호출해야 실제로 실행된다.
함수는 매개변수를 통해 외부에서 데이터를 전달받을 수 있다. 매개변수는 함수를 정의할 때 사용하는 변수이고, 인수는 함수를 호출할 때 실제로 전달하는 값이다.
함수는 `return` 문을 사용하여 결과값을 반환할 수 있다. 반환값이 없는 경우에는 `None`이 반환되며, 여러 개의 값을 동시에 반환하는 것도 가능하다.
변수는 사용 범위에 따라 지역 변수와 전역 변수로 구분된다. 지역 변수는 함수 내부에서만 사용할 수 있고 함수가 종료되면 사라진다. 전역 변수는 프로그램 전체에서 사용할 수 있으며, 함수 안에서 전역 변수의 값을 변경하려면 `global` 키워드를 사용해야 한다.

## 1. 함수 정의와 호출

* `def` 키워드를 사용하여 함수를 정의하고 호출하여 실행한다.

```python
def greet():
    print("안녕하세요!")

greet()
```

## 2. 매개변수와 인수

* 매개변수는 함수를 정의할 때 사용하는 변수이고, 인수는 호출 시 전달하는 값이다.

```python
def say_hello(name):
    print(f"안녕, {name}!")

say_hello("반가워")
```

## 3. 반환값(return)

* `return`을 사용하여 함수의 결과를 반환한다.

```python
def add(a, b):
    return a + b

result = add(3, 5)
print(result)
```

## 4. 전역 변수와 global

* 함수 내부에서 전역 변수의 값을 수정할 때 `global` 키워드를 사용한다.

```python
gx = 100

def my_func():
    global gx
    gx = 200

my_func()
print(gx)
```
