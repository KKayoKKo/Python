# 📝 6장 파이썬 자료구조 I (리스트)

## 1. 리스트(List)의 개념

* **정의**: 여러 개의 항목(Item)들을 순서대로 저장하는 컨테이너(자료구조)입니다.
* **특징**:
* 대괄호(`[ ]`)를 사용하여 생성하며, 항목들은 쉼표(`,`)로 구분합니다.
* 하나의 리스트에 정수, 실수, 문자열 등 **서로 다른 자료형의 데이터를 혼합하여 저장**할 수 있습니다.
* 비어 있는 빈 리스트는 `list()` 또는 `[]`로 만들 수 있습니다.



## 2. 인덱싱과 슬라이싱

### 📍 인덱싱 (Indexing)

* 리스트의 특정 항목 위치를 지정하여 값을 가져오거나 변경하는 방법입니다.
* 인덱스는 **0부터 시작**하며, 음수 인덱스(`-1`)는 리스트의 마지막 항목을 가리킵니다.

### ✂️ 슬라이싱 (Slicing)

* 리스트에서 일정 범위의 항목들을 한 번에 잘라내어 새로운 리스트를 만드는 방법입니다.
* **형식**: `list[시작인덱스:종료인덱스]` (종료 인덱스 직전 항목까지만 포함됨)

```python
nums = [10, 20, 30, 40, 50]
print(nums[1:4])  # 인덱스 1부터 3까지 출력 ➡️ [20, 30, 40]

```

## 3. 리스트 주요 연산 및 메서드(Method)

### ➕ 기본 연산

* **덧셈 (`+`)**: 두 리스트를 하나로 연결합니다.
* **곱셈 (`*`)**: 리스트의 항목들을 지정한 횟수만큼 반복합니다.
* **길이 (`len()`)**: 리스트에 담긴 항목의 개수를 반환합니다.

### 🛠️ 자주 쓰이는 메서드

* `append(x)`: 리스트의 맨 끝에 항목 `x`를 추가합니다.
* `insert(index, x)`: 지정한 인덱스 위치에 항목 `x`를 삽입합니다.
* `remove(x)`: 리스트에서 값이 `x`인 첫 번째 항목을 삭제합니다.
* `pop(index)`: 지정한 인덱스의 항목을 지우면서 그 값을 반환합니다. (인덱스 생략 시 맨 마지막 항목 제거)
* `index(x)`: 값이 `x`인 항목의 인덱스 번호를 반환합니다.
* `count(x)`: 리스트 내에 존재하는 값 `x`의 개수를 셉니다.
* `sort()`: 리스트의 항목들을 오름차순으로 정렬합니다. (`reverse=True` 설정 시 내림차순)

## 4. 리스트와 반복문

* 리스트의 모든 항목을 순서대로 꺼내어 처리할 때 `for-in` 루프를 사용하면 코드가 매우 직관적이고 깔끔해집니다.

```python
scores = [90, 85, 70]
for score in scores:
    print(score)

```

## 5. 리스트 함축 (List Comprehension)

* 새로운 리스트를 생성할 때 복잡한 `for` 문과 `if` 조건문을 한 줄로 압축하여 간결하게 작성하는 파이썬의 강력한 문법입니다.

```python
# 0부터 9까지의 수 중 짝수만 제곱하여 리스트 생성
evens_squared = [x**2 for x in range(10) if x % 2 == 0]

```

## 6. 2차원 리스트 (2D List)

* 리스트 내부에 또 다른 리스트를 항목으로 가지는 구조로, 행(Row)과 열(Column)로 이루어진 테이블 형태의 데이터를 표현할 때 사용합니다.
* 예시: 바둑판 화면 표현, 행렬 계산, **Tic-Tac-Toe(틱택토) 게임 보드** 등.

```python
# 3x3 크기의 빈 보드 생성
board = [[' ' for x in range(3)] for y in range(3)]
print(board[0][0])  # 0행 0열 항목 접근

```

---

## 📌 핵심 요약

1. **리스트**는 다양한 타입의 데이터를 순서대로 저장하는 가변(Mutable) 컨테이너이다.
2. 리스트의 특정 범위 요소를 추출할 때는 슬라이싱(`[:]`)을 사용하며, 종료 인덱스는 포함되지 않는다.
3. 데이터를 맨 뒤에 추가할 때는 **`append()`**, 특정 위치에 넣을 때는 `insert()`를 활용한다.
4. 리스트 함축(List Comprehension)을 사용하면 반복문과 조건문이 결합된 리스트 생성을 한 줄로 줄일 수 있다.
5. 표 형태의 데이터나 게임 판을 구현할 때는 리스트를 중첩한 **2차원 리스트**를 사용한다.
