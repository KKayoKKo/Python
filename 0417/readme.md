# 📝 6장 파이썬 자료구조 I (리스트)

### 6장 파이썬 자료구조 I (리스트) 요약

리스트는 여러 개의 데이터를 순서대로 저장하는 자료구조이다. 대괄호(`[]`)를 사용하여 생성하며, 하나의 리스트 안에 정수, 실수, 문자열 등 서로 다른 자료형의 데이터를 함께 저장할 수 있다. 또한 리스트는 값을 자유롭게 추가하거나 수정할 수 있는 가변(Mutable) 객체이다.
리스트의 각 요소는 인덱스를 사용하여 접근할 수 있다. 인덱스는 0부터 시작하며, 음수 인덱스를 사용하면 뒤에서부터 요소를 참조할 수 있다. 또한 슬라이싱을 사용하면 리스트의 특정 범위를 추출하여 새로운 리스트를 만들 수 있다.
리스트는 다양한 연산과 메서드를 제공한다. `append()`는 요소를 추가하고, `insert()`는 원하는 위치에 삽입하며, `remove()`는 특정 값을 삭제한다. `pop()`은 요소를 제거하면서 반환하고, `sort()`는 리스트를 정렬한다. 또한 `len()` 함수를 사용하여 리스트의 길이를 확인할 수 있다.
리스트는 반복문과 함께 자주 사용된다. `for-in` 문을 이용하면 리스트의 모든 요소를 순서대로 처리할 수 있으며, 리스트 함축(List Comprehension)을 사용하면 반복문과 조건문을 한 줄로 표현하여 새로운 리스트를 간결하게 생성할 수 있다.
리스트 안에 또 다른 리스트를 저장한 구조를 2차원 리스트라고 한다. 2차원 리스트는 행과 열로 구성된 데이터를 표현할 때 사용하며, 행렬 계산이나 게임 보드 구현 등에 활용된다.

## 1. 인덱싱과 슬라이싱

* 인덱스를 이용해 요소에 접근하고, 슬라이싱으로 특정 범위를 추출할 수 있다.

```python
nums = [10, 20, 30, 40, 50]

print(nums[0])
print(nums[1:4])
```

## 2. 리스트 메서드

* `append()`, `insert()`, `remove()` 등을 사용하여 리스트를 수정할 수 있다.

```python
fruits = ["apple", "banana"]

fruits.append("orange")
fruits.insert(1, "grape")
fruits.remove("banana")

print(fruits)
```

## 3. 리스트와 반복문

* `for-in` 문을 사용하여 리스트의 모든 요소를 순서대로 처리한다.

```python
scores = [90, 85, 70]

for score in scores:
    print(score)
```
