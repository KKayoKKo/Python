# 📝 7장 파이썬 자료구조 II

튜플은 리스트와 비슷한 자료구조이지만 한 번 생성하면 값을 변경할 수 없는 불변(Immutable) 객체이다. 소괄호 `()`를 사용하여 생성하며, 인덱싱과 슬라이싱은 가능하지만 요소를 추가하거나 삭제할 수는 없다. 또한 여러 값을 하나의 튜플로 묶는 패킹(Packing)과 튜플의 값을 여러 변수에 나누어 저장하는 언패킹(Unpacking)을 지원한다.
세트는 수학의 집합을 표현한 자료구조로, 중복된 값을 허용하지 않으며 순서가 없다. 중괄호 `{}` 또는 `set()` 함수로 생성할 수 있으며, 인덱스를 사용할 수 없다. 세트는 교집합, 합집합, 차집합과 같은 집합 연산을 수행할 때 유용하다.
딕셔너리는 키(Key)와 값(Value)의 쌍으로 데이터를 저장하는 자료구조이다. 키를 이용하여 값을 빠르게 검색할 수 있으며, 키는 중복될 수 없다. 딕셔너리는 `keys()`, `values()`, `items()` 등의 메서드를 제공한다.
문자열은 변경할 수 없는 시퀀스 자료형으로 다양한 문자열 처리 기능을 제공한다. `split()`은 문자열을 분리하여 리스트로 반환하며, `isalpha()`, `isdigit()`, `isspace()` 등을 이용해 문자열의 특성을 확인할 수 있다.

## 1. 튜플(Tuple)

* 튜플은 값을 변경할 수 없는 시퀀스 자료구조이다.

```python
point = (10, 20)

x, y = point

print(x)
print(y)
```

## 2. 세트(Set)

* 세트는 중복을 허용하지 않으며 집합 연산을 지원한다.

```python
a = {1, 2, 3}
b = {3, 4, 5}

print(a & b)
print(a | b)
```

## 3. 딕셔너리(Dictionary)

* 딕셔너리는 키와 값의 쌍으로 데이터를 저장한다.

```python
student = {"name": "태욱", "score": 95}

print(student["name"])
print(student["score"])
```
