# 📝 7장 파이썬 자료구조 II

## 1. 튜플 (Tuple)

* **정의**: 리스트와 유사하지만, 한번 생성되면 **값을 수정할 수 없는(Immutable)** 시퀀스 자료구조입니다.
* **특징**:
* 소괄호(`( )`)를 사용하여 생성합니다. (괄호를 생략해도 자동으로 튜플로 인식됩니다.)
* 요소가 1개뿐인 튜플을 만들 때는 반드시 뒤에 쉼표를 붙여야 합니다. (예: `single_tuple = (10, )`)
* 값을 수정하거나 삭제하는 메서드(`append`, `remove` 등)는 사용할 수 없으며, 인덱싱과 슬라이싱만 가능합니다.


* **패킹과 언패킹**:
* **패킹(Packing)**: 여러 값을 하나의 튜플로 묶는 것.
* **언패킹(Unpacking)**: 튜플의 요소를 여러 변수에 나누어 담는 것. (예: `(id, domain) = address.split("@")`)



## 2. 세트 (Set)

* **정의**: 수학의 집합을 표현한 자료구조로, **중복을 허용하지 않고 순서가 없는(Unordered)** 컨테이너입니다.
* **특징**:
* 중괄호(`{ }`)를 사용하거나 `set()` 함수로 생성합니다. (단, 빈 세트는 반드시 `set()`으로 생성해야 합니다. `{}`는 빈 딕셔너리가 됩니다.)
* 순서가 없기 때문에 인덱싱(`set[0]`)을 사용할 수 없습니다.


* **집합 연산**:
* **교집합**: `s1 & s2` 또는 `s1.intersection(s2)`
* **합집합**: `s1 | s2` 또는 `s1.union(s2)`
* **차집합**: `s1 - s2` 또는 `s1.difference(s2)`



## 3. 딕셔너리 (Dictionary)

* **정의**: 키(Key)와 값(Value)의 쌍을 저장하는 자료구조입니다. (사전에서 단어와 뜻을 찾는 것과 유사)
* **특징**:
* 중괄호 `{Key: Value}` 형태로 항목을 저장합니다.
* **키(Key)는 중복될 수 없으며**, 항목을 찾을 때 인덱스 대신 키를 사용합니다.


* **주요 메서드**:
* `keys()`: 딕셔너리의 모든 키를 반환
* `values()`: 딕셔너리의 모든 값을 반환
* `items()`: 모든 키와 값의 쌍을 튜플 형태로 반환



## 4. 문자열 (String) 심화 연산

파이썬에서 문자열은 튜플처럼 변경 불가능한(Immutable) 시퀀스 자료구조에 속하며, 다양한 내장 메서드를 제공합니다.

* **텍스트 처리 메서드**:
* `split(기준문자)`: 문자열을 특정 기준 문자로 쪼개어 **리스트**로 반환합니다. (예: 주소나 이메일 분리 시 유용)
* `isalpha()`: 문자열이 모두 알파벳(한글 포함 문자)이면 `True`
* `isdigit()`: 문자열이 모두 숫자이면 `True`
* `isspace()`: 문자열이 모두 공백이면 `True`

## 📌 핵심 요약 (Summary)

1. **튜플**은 리스트와 똑같으나 내부에 저장된 요소를 **절대 변경할 수 없다(Immutable)**.
2. **세트**는 집합 연산(교집합, 합집합 등)에 특화되어 있으며, **중복된 값을 자동으로 제거**한다.
3. **딕셔너리**는 **`Key-Value` 쌍**으로 이루어져 있어 특정 키를 기반으로 빠르게 값을 검색할 때 사용한다.
4. 빈 자료구조 생성 시, 빈 세트는 무조건 `set()`을 써야 하며 `{}`를 사용하면 **빈 딕셔너리**가 생성된다.
5. **`split()`** 메서드는 문자열을 잘라 리스트로 만들어 주므로 텍스트 분석 및 데이터 가공에 자주 쓰인다.
