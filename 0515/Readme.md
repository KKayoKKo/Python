# 📝 8장 객체와 클래스

객체 지향 프로그래밍(OOP)은 데이터와 기능을 하나의 객체로 묶어 프로그램을 구성하는 방식이다. 객체는 속성과 메서드로 이루어지며, 현실 세계의 사물을 모델링하여 프로그램을 설계할 수 있다.
객체는 상태를 나타내는 속성(Attribute)과 동작을 나타내는 메서드(Method)로 구성된다. 속성은 객체가 가지고 있는 데이터이고, 메서드는 객체가 수행할 수 있는 기능이다.
클래스는 객체를 만들기 위한 설계도이며, 클래스를 통해 실제로 생성된 객체를 인스턴스라고 한다. 하나의 클래스로 여러 개의 인스턴스를 만들 수 있다.
생성자인 `__init__()` 메서드는 객체가 생성될 때 자동으로 호출되어 속성을 초기화한다. 또한 `self`는 현재 객체 자신을 가리키며, 클래스의 메서드에서 첫 번째 매개변수로 사용된다.
정보 은닉은 객체의 중요한 데이터를 외부에서 직접 수정하지 못하도록 보호하는 기법이다. 파이썬에서는 변수 이름 앞에 `__`를 붙여 private 변수처럼 사용할 수 있다.

## 1. 클래스와 인스턴스

* 클래스는 객체를 만들기 위한 설계도이며, 인스턴스는 실제 생성된 객체이다.

```python
class Car:
    pass

my_car = Car()
```

## 2. 생성자와 self

* `__init__()`는 객체 생성 시 자동으로 호출되며, `self`는 현재 객체를 가리킨다.

```python
class Car:
    def __init__(self, color, speed):
        self.color = color
        self.speed = speed

my_car = Car("blue", 0)
```

## 3. 정보 은닉

* 변수 이름 앞에 `__`를 붙여 외부의 직접 접근을 제한할 수 있다.

```python
class Student:
    def __init__(self, name):
        self.__name = name
```
