# 📝 8장 객체와 클래스

## 1. 객체 지향 프로그래밍 (OOP)

* **개념**: 서로 관련 있는 데이터와 함수를 하나의 덩어리로 묶어 객체(Object)를 만들고, 이 객체들이 상호작용하도록 프로그램을 구성하는 방식입니다.
* **비교**:
* **절차 지향**: 실행되는 순서(프로시저)와 함수 중심의 프로그래밍 방법.
* **객체 지향**: 데이터와 이를 처리하는 함수를 객체 단위로 묶어 관리하는 방법.



## 2. 객체(Object)의 구성 요소

객체는 크게 상태(속성)와 동작(기능)으로 표현됩니다.

* **속성 (Attribute)**: 객체가 가지고 있는 데이터 (변수로 구현)
* 예: 자동차의 속도, 색상, 모델명


* **메서드 (Method)**: 객체가 할 수 있는 동작이나 기능 (함수로 구현)
* 예: 출발하기, 가속하기, 정지하기



## 3. 클래스(Class)와 인스턴스(Instance)

* **클래스**: 객체를 만들기 위한 설계도(틀)입니다. (예: 붕어빵 틀)
* **인스턴스**: 클래스라는 설계도를 바탕으로 메모리에 실제 생성된 **객체**입니다. (예: 붕어빵 틀로 찍어낸 실제 붕어빵)

```python
# 클래스(설계도) 정의
class Car:
    pass

# 인스턴스(객체) 생성
my_car = Car()

```

## 4. 생성자 (`__init__` 메서드)와 `self`

* **생성자 (`__init__`)**: 객체가 생성될 때 속성(초기값)을 설정하기 위해 **자동으로 호출되는 특수 메서드**입니다.
* **`self` 매개변수**: 메서드가 호출될 때, **현재 어떤 객체가 호출했는지 그 객체 자신을 가리키는 변수**입니다. 메서드의 첫 번째 매개변수는 무조건 `self`여야 합니다.

```python
class Car:
    def __init__(self, color, speed):
        self.color = color  # 객체의 속성 초기화
        self.speed = speed

# 객체 생성 시 생성자에 매개변수 전달
my_car = Car("blue", 0)

```

## 5. 정보 은닉 (Information Hiding)

* **개념**: 외부에서 객체의 핵심 속성을 직접 변경하지 못하도록 제한하고, 메서드를 통해서만 안전하게 접근하도록 하는 기법입니다.
* **파이썬에서의 구현**: 변수 이름 앞에 밑줄 두 개(`__`)를 붙이면 private 변수가 되어 외부에서 직접 접근할 수 없습니다.

```python
class Student:
    def __init__(self, name):
        self.__name = name  # 외부 접근 차단

# 변수에 안전하게 접근하기 위해 Getter와 Setter 메서드를 활용함

```

## 6. 특수 메서드 (Special Method)

* 파이썬이 미리 정의해 둔 내장 메서드로, 언더바 두 개가 앞뒤로 붙어 있어 **던더(Dunder) 메서드**라고도 부릅니다.
* `__str__(self)`: 객체 자체를 `print()` 함수로 출력할 때 보여줄 문자열 형태를 지정합니다.
* `__add__(self, other)`: 객체 간의 더하기(`+`) 연산자를 정의할 때 사용합니다. (연산자 오버로딩)

## 📌 핵심 요약

1. 객체 지향 프로그래밍(OOP)은 데이터(속성)와 기능(메서드)을 하나의 객체로 묶어 개발하는 방식이다.
2. **클래스**는 객체를 생성하기 위한 설계도이며, 이를 통해 생성된 실체를 **인스턴스**라고 한다.
3. **`__init__` 메서드**는 객체 생성 시 속성을 초기화하는 생성자 함수이다.
4. `self`는 메서드를 호출한 객체 자신을 가리키며, 파이썬 메서드의 첫 번째 매개변수로 반드시 기술해야 한다.
5. 변수명 앞에 `__`을 붙여 외부의 직접적인 접근을 막는 **정보 은닉**을 지원한다.
